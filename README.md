# Lexim Tex Sourcing

A single-page portfolio website for **Lexim Tex Sourcing Ltd.**, an apparel sourcing and manufacturing hub connecting global brands with factories across Asia (knitwear, denim, sweaters, sportswear, and more).

## Tech Stack

- Plain HTML5 / CSS3 / vanilla JavaScript (no build step or framework)
- [Bootstrap 5.3.3](https://getbootstrap.com/) (via CDN) for layout and components
- [Bootstrap Icons](https://icons.getbootstrap.com/) (via CDN)
- [Inter](https://fonts.google.com/specimen/Inter) webfont (via Google Fonts CDN)

## Project Structure

```
.
├── index.html            # Main (and only) page
└── assets/
    ├── css/style.css     # Custom styles
    ├── js/
    │   ├── script.js     # Nav, preloader, scroll effects, etc.
    │   └── script2.js     # Gallery / lightbox behavior
    └── img/               # Hero, category, and gallery images
```

## Page Sections

Home · About · Gallery · Why Us · Products · Sourcing · Clients · Contact


## Deployment

The site is intended to be served as a static site via **GitHub Pages** (or any static host) — no build step is needed.
